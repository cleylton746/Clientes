# Clientes
Hub para clientes
Funcionalidades
Painel Centralizado: Visualização rápida da lista de clientes ativos e seus principais dados de contato.
Navegação Rápida: Links de atalho para sistemas externos, relatórios e documentos de cada cliente.
Interface Leve: Carregamento instantâneo por utilizar estrutura HTML nativa sem dependências pesadas.

🛠️ Tecnologias Utilizadas
Linguagem Principal: HTML5
(Opcional) Estilização: CSS3 (para organização visual e layout responsivo)

⚙️ Pré-requisitos

Por se tratar de uma aplicação baseada em HTML, não é necessário instalar navegadores ou servidores complexos. Você precisa apenas de:
Um navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
Um editor de código (como VS Code) caso queira alterar o conteúdo do painel.

🔧 Como Rodar o Projeto
# 1. Clone o repositório
git clone https://github.com/seu-usuario/hub-clientes-kim.git

# 2. Acesse a pasta do projeto
cd hub-clientes-kim

# 3. Abra o arquivo index.html no seu navegador
# No Windows:
start index.html

# No Mac:
open index.html

# No Linux:
xdg-open index.html
